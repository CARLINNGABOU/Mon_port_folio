# Portfolio

Ce projet est un site web de portfolio personnel développé pour présenter les compétences, réalisations et expériences professionnelles de son auteur. Il s'agit d'un site web statique composé principalement de fichiers HTML, CSS et JavaScript.

---

## Structure du projet

- **index.html** : Page principale du site web.
- **styles.css** : Feuille de style principale pour la personnalisation du design.
- **scripts.js** : Script principal pour les interactions, animations et soumission de formulaire via AJAX.
- **img/** : Dossier contenant vos images que vous allez uploader.

---

## Fonctionnalités

- Présentation des informations personnelles et professionnelles
- Animations et transitions pour améliorer l'expérience utilisateur
- Utilisation de frameworks et bibliothèques populaires (Bootstrap, AOS)

---

## Utilisation

1. Ouvrir le fichier `index.html` dans un navigateur web ou lancer avec Live Server pour visualiser le portfolio.

---

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Bootstrap

## Configuration service d'envoi d'e-mail

Ce site web utilise [Formspree](https://formspree.io), une solution simple qui nécessite aucun code backend, et envoie directement les messages sur leur boite mail.

1. Créez ou connectez-vous à votre conmpte [Formspree](https://formspree.io).
2. Une fois connecté, vous serez rédiriger vers votre tableau de bord. Puis cliquer sur +.
3. Renseignez le nom du formulaire, le projet et l'adresse e-mail chargée de recevoir les mails, puis confirmer.
4. Copier l'URL (EndPoint) dans la constante `FORMSPREE_ENDPOINT` dans `scripts.js`.
5. N'oubliez pas de bien suivre les instructions sur [Formspree](https://formspree.io).
